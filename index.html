《苍穹-离界》Firmament · Transcendence

双界切换的俯视角动作解谜游戏

本科毕业设计 · 2026.01 — 2026.05 · 独立开发

UE5.4C++ / 蓝图混合架构Gameplay Ability SystemEnhanced InputUWorldSubsystem行为树 · NavMeshUMG / SlateLevel Sequence

俯视角动作解谜游戏，毕业设计，从架构到关卡一个人做完。底层用 C++ 搭框架，参数与表现层交给蓝图；核心机制「现实界 / 离界」没有写成关卡里的一次性触发器，而是做成受 GAS 状态标签驱动的 Hold 技能——按 Space 翻转世界，断桥与栅栏跟着切换可见性和碰撞，可走路径随之重算。战斗侧做了鼠标反投影锁定朝向、三段连击、范围大招与法力消耗，AI 侧是行为树 + NavMesh，首领两阶段：血量归零后假死起身，移速 1.25 倍、攻击半径 1.2 倍。串起开场 Level Sequence、能力解锁、机关解谜到通关的完整流程。

《苍穹-离界》实机演示 · 2 分 06 秒bilibili.com↗

核心功能与亮点

核心玩法 ·「现实界 / 离界」双界切换

  • 能力化封装：摒弃硬编码的一次性关卡触发器，将世界切换封装为 Hold 类型技能 UAuraGameplayAbility_WorldSwitchHold，统一纳入 GAS 的激活检查、标签互斥与事件流管理。
  • 跨界空间解谜：按下 Space 即可在「现实界 State.World.Real」与「离界 State.World.Spirit」间实时翻转；隐藏断桥 BP_WorldSwitchBridge 与阻挡栅栏 BP_WorldSwitchZhalan 依据当前世界状态自动切换可见性与物理碰撞，打通解谜通行路径与战斗空间。

基于 GAS 的战斗与属性反馈

  • 射线朝向锁定与多段连击：通过鼠标屏幕坐标反投影与射线检测 FaceControlledPawnToCursor 实时计算攻击朝向并维护朝向锁定窗口；结合 FAuraAttackHitTraceConfig 配置多段连击蒙太奇的球形检测半径与距离，由 AnimNotify 精准触发命中结算。
  • 范围大招与法力消耗：基于 UAuraGameplayAbility_UltimateRadial 实现法力校验、扣减与范围伤害 GameplayEffect 施加，结合 Niagara 武器刀光拖尾 SwordTrailVFX 强化打击感。

两阶段首领战与智能寻路

  • 行为树与导航网格：基于 AAuraEnemyAIController、行为树 BT_Enemy、黑板 BB_Enemy 与 Recast NavMesh 构建孤岛地形 A* 寻路，实现小怪巡逻、感知追击、攻击与概率掉落恢复血瓶。
  • 假死复活与二阶段狂暴：在敌人基类中设计首领两阶段状态机——一阶段血量归零后触发眩晕与起身蒙太奇，随后动态提升 1.25 倍移速、扩大 1.2 倍攻击半径并覆写攻击蒙太奇播放速率，大幅拉升终局压迫感。

动态引导 UI 与电影级开场

  • 开场序列管控：编写 AAuraIntroManager 统一调度开始菜单、LS_Intro_Island 开场镜头播放与跳过逻辑，采用计数配对机制 ResetIgnoreMoveInput 安全恢复玩家控制权与混合视角。
  • 能力驱动的动态提示：用 C++ 编写 UAuraTutorialPromptWidget，监听玩家穿过红色传送门解锁「双界切换」与「终极技能」的时机，在左下角动态追加操作指引。

技术实现与架构亮点

子系统 + 接口解耦

  • 设计继承 UWorldSubsystem 的 UAuraWorldSubsystem 作为全局唯一世界状态持有者；世界切换时由子系统遍历并广播通知所有实现 IWorldSwitchableInterface 的场景对象（AAuraWorldSwitchBase），彻底消除控制器与关卡 Actor 之间的直接耦合。

属性访问器宏与安全裁剪

  • 利用 ATTRIBUTE_ACCESSORS 宏统一生成 Health / Mana / AttackPower 属性接口，并在 PreAttributeChange 中集中执行上下限 Clamp；外部系统禁止直接调用 Setter，数值变更全部由 Instant / Infinite 型 GameplayEffect 驱动。

GE 句柄追踪修复区域残留缺陷

  • 针对火焰危险区域 BP_FireArea 的持续扣血逻辑，使用 TMap<FActiveGameplayEffectHandle, TWeakObjectPtr<UAbilitySystemComponent>> 精确记录激活句柄，在 EndOverlap 或关卡销毁时精准移除对应 Infinite GE，根治「离开火区仍持续掉血」的生命周期缺陷。

虚函数钩子扩展与 MVC 界面解耦

  • 在敌人攻击基类 UAuraGameplayAbility_EnemyAttack 中设计冷却、伤害延迟与播放速率虚函数钩子，供首领技能子类按阶段覆写而无需复制整套攻击管线；通过 UOverlayWidgetController 与 EnemyHealthWidgetController 订阅属性委托并转发至 UMG，实现 UI 表现层与 GAS 数据层完全分离。

个人贡献

  • 独立完成全部 C++ 核心类（AuraCharacterBase、AuraPlayerController、AuraAttributeSet、AuraWorldSubsystem、AuraIntroManager、AuraEffectActor 等）的架构设计与编码实现。
  • 独立完成孤岛关卡 MP_Island 搭建、NavMesh 配置、开场 Level Sequence 镜头剪辑、3 类核心 GameplayAbility 及全套 UMG / Slate 交互界面的集成，并通过 11 项核心用例测试。

UE5 第三人称动作游戏Action Combat Prototype

锁定、连段、闪避与弹反的战斗手感打磨

2024.07 — 2024.10 · 独立开发

UE5 蓝图动画蒙太奇Root Motion物理判定AI 行为树UMG

3 个月内从零做到可玩的动作原型，重点全在战斗手感。弹反、锁定、闪避、五段普攻与敌人 AI 都已跑通：中键球形检测锁定最近敌人，锁定后摄像机自动调距离和朝向，缓解目标丢失与镜头抖动；闪避用短无敌帧配 Root Motion，判定挂在 Anim Notify 上。参考《只狼》的弹反与锁定、《浪人崛起》的锁定态摄像机、《原神》的平 A 连段节奏。

战斗系统

敌人锁定

  • 鼠标中键触发球形检测自动锁定最近敌人并给出 UI 标识；锁定后摄像机动态调整视角与距离，提升战斗信息可读性，缓解目标丢失与镜头抖动。

八向移动与闪避垫步

  • 非锁定时自由旋转移动，锁定状态下使用 2D 混合空间动态调整方向；闪避采用短无敌帧设定，结合 Root Motion 播放闪避动画，保证战斗节奏紧凑。

血量信息分层

  • 小型敌人血条置于头顶，Boss 血条固定于屏幕底部，按威胁等级分层呈现战斗信息。

攻击与连段

连击逻辑

  • 基于攻击计数器动态切换不同攻击动画，实现自然的连段衔接。

判定与手感

  • 以 Anim Notify 触发精确攻击判定并结合武器碰撞检测；通过前后摇控制避免动画突兀中断，同时把攻击、弹反、闪避的输入延迟压在可接受范围内。

技术实现

动画与物理

  • 使用 Montage 保证攻击动画连贯，结合 Root Motion 提升动作真实感；以 LineTrace 与球形检测组合提高命中精度、避免误判。

摄像机策略

  • 非锁定状态保持自由视角，锁定后自动调整朝向与距离，让战斗信息始终清晰。

个人贡献

  • 独立完成锁定、连段、闪避、弹反与血量 UI 等核心战斗模块的设计与实现。
  • 独立完成动画蒙太奇编排、判定时机调优与测试场景搭建，跑通从输入到打击反馈的完整链路。

《纸狼》Paper Wolf · 2D Fighter

不依赖商业引擎、从零手写的 2D 格斗游戏

2024.03 — 2024.06 · 独立开发

C++11Win32 APIGDI+双缓冲AABB 碰撞fstream 录像

不用任何商业引擎，C++11 + Win32 API 从零写出来的 2D 格斗游戏，致敬《死神 VS 火影》。自己封装消息循环处理键鼠输入，GDI+ 绘制配双缓冲压住高频重绘的闪烁，定时器控逻辑帧率；碰撞是自定义 AABB 逐帧矩形相交。除了对战本身，还做了两样工具：可实时保存和试玩的地图编辑器，以及用 fstream 把操作指令逐帧序列化、能暂停拖进度的对局回放。

《纸狼》实机演示bilibili.com↗

玩法与体验

格斗手感

  • 模仿《死神 VS 火影》的角色扮演式对战，支持流畅操控、攻击、招架与空中受击等状态。

智能摄像机与动态背景

  • 摄像机自动跟随双方保持角色处于视野中心，并限制在边界内移动；配合动态背景增强沉浸感。

精确碰撞检测

  • 基于自定义 AABB 碰撞盒逐帧做矩形相交检测，优化碰撞体积设计，避免穿模与瞬移。

工具链

地图编辑器

  • 支持自定义地图创建、实时保存与快速测试，可放置方块与小平台并即时预览。

对局回放

  • 自动录制每场对战，使用 fstream 对操作指令逐帧序列化 / 反序列化，由定时器驱动完整对局回放，支持进度展示与暂停。

技术实现

底层框架

  • 封装 Win32 单线程消息循环处理键鼠输入；GDI+ 绘制配合双缓冲解决高频重绘闪烁，定时器控制逻辑帧率。

动画系统

  • 通过关键帧动画与同步播放技术，保证动作衔接流畅自然。

个人贡献

  • 独立完成核心逻辑设计与实现，包括角色控制、碰撞检测、动画播放等关键模块。
  • 主导设计并实现地图编辑器与对局回放系统，显著提升可玩性与工具效率。
  • 通过代码结构与算法优化，提升运行效率与稳定性。

UE 俯视角 RogueLike DemoTop-down Roguelike

上下半身分离动画 + 行为树驱动的怪物 AI

个人练习项目 · 独立开发

UE5 蓝图上下半身动画分离行为树 AIAnim NotifyNiagara 粒子UMG

UE5 俯视角 RogueLike 动作 Demo，练的是动画分层和行为树。角色上下半身分开控制：上半身攻击时优先播攻击动画，否则跟下半身同步；下半身按移动速度在走和跑之间切换。战斗是远程投射物循环——攻击动画指定帧生成火球，命中即结算伤害并弹出伤害数字。怪物默认在区域内随机游荡，被打了就锁定玩家追击。

角色与动画

精准移动控制

  • 通过键盘输入实时调整角色坐标，依据当前速度方向调整朝向，保证转身流畅自然。

上下半身独立控制

  • 采用半身独立控制机制：上半身攻击时优先播放攻击动画，否则与下半身同步；下半身依据移动速度在行走 / 奔跑动画间动态切换，使表现自然生动。

战斗循环

远程攻击

  • 角色自动朝向鼠标目标方向；在攻击动画指定帧生成火球并同步播放投射特效，火球沿直线飞行，3 秒后自动销毁，命中障碍或敌人时立即触发爆炸。

受击反馈

  • 命中即结算伤害并生成由小变大、逐渐透明消失的动态伤害数字，叠加爆炸特效强化打击感。

怪物 AI 与工程

行为树状态切换

  • 用 UE5 行为树管理怪物逻辑：默认在设定区域内随机游荡模拟巡逻，受到攻击后锁定玩家并追击。

表现与优化

  • Anim Notify 精确控制攻击与受击帧事件；摄像机智能跟随保持角色居中；合理调整碰撞体积，避免穿模与卡位。

个人贡献

  • 独立完成角色操控、战斗机制、怪物 AI 等核心系统开发。
  • 设计并优化动画分层系统，提升动作流畅度与真实感。

《宝可梦世界》Pokemon World · Text RPG

数据驱动的 C++ 策略养成文字游戏

个人练习项目 · 独立开发

C++面向对象数据驱动文件持久化多文件架构

用 C++ 写的回合制养成文字游戏，重点是数据驱动。宝可梦、技能、地图全部由外部文件配置，改内容不用动代码；代码只管规则和流程。做完了图鉴、探索、战斗、背包与存档持久化，按战斗 / 图鉴 / 地图 / UI 拆成多文件结构。

玩法设计

策略养成

  • 模拟宝可梦养成与回合制战斗：包含技能选择、伤害计算与状态效果，玩家培养队伍走出迷宫。

图鉴与探索

  • 图鉴系统展示宝可梦信息满足收集欲；地图包含多种地形与随机事件，供玩家自由探索。

技术实现

数据驱动

  • 宝可梦、技能、地图数据均通过外部文件配置，修改与扩展无需改动代码。

模块与持久化

  • 多文件架构划分战斗、图鉴、地图、UI 等模块；使用 vector 存储图鉴数据，配合文件读写实现存档持久化。

个人贡献

  • 独立完成战斗系统、图鉴系统与 UI 系统的设计与实现。
  • 主导多文件架构设计，提升代码可读性与可维护性，并优化数据读写效率。
